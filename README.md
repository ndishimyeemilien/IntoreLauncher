# Intore Clock

A lightweight digital clock application that shows the current time in multiple time zones.

## Features
- Real-time digital clock updates every second
- Displays several global time zones at once
- Backend API for time-zone data
- Frontend UI with a modern desktop-style layout
- Cross-platform compatibility using Node.js and a browser interface

## Run the app

```bash
npm install
npm start
```

Then open:

```text
http://localhost:3000
```
